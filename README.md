# World in One Day — Sunday 22 November 2026

A program that draws one 1024×1024 poster summing up the world's news of
Sunday 22 November 2026: COP31 ending with no deal in Antalya, Iran striking
Bahrain, the capture of cartel boss "El Chapo Isidro" in Mexico, a Russian
drone hitting a Kyiv apartment block, BepiColombo entering orbit around
Mercury, and a deadly factory fire in Indonesia.

Run it with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

It writes `entry.png` — a deterministic PNG drawn with a hand-built
rasteriser, bitmap font and PNG encoder, pure Node 22 standard library.
